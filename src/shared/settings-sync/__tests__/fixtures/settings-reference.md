# Claude Code settings reference

## All settings

| Key | Description | Topic | Scope |
| :--- | :----------- | :--- | :---- |
| [`advisorModel`](#advisormodel) | Pick the model used by the advisor | Model and responses | Any file |
| [`model`](#model) | Change the default model | Model and responses | Any file |
| [`permissions.allow`](#permissions-allow) | Approve listed tool uses | Permission settings | Any file |
| [`sandbox.enabled`](#sandbox-enabled) | Turn on Bash sandboxing | Sandbox settings | Any file |
| [`sandbox.credentials.files`](#sandbox-credentials-files) | Block reads of credential files with an escaped \| pipe | Sandbox settings | Any file |
| [`attribution.commit`](#attribution-commit) | Change or hide commit attribution | Git and attribution | Any file |
| [`managedOnly`](#managedonly) | (Managed settings only) Organization policy | Enterprise | Managed |
| [`managedByScope`](#managedbyscope) | Organization policy without a description marker | Enterprise | Managed |
| [externalLink](/docs/en/other-page) | This is not a same-page setting link | Other | Any file |
| [`not-a-setting`](#not-a-setting) | This key is not legal | Other | Any file |
